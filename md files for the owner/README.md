# Design Library

Reusable design archetypes for generating a project's root `DESIGN.md`.

## Files

- `BASE.md` — general visual philosophy and reusable principles.
- `WEB-APP.md` — interactive web applications.
- `DASHBOARD.md` — data-heavy dashboards and monitoring interfaces.
- `MARKETING-SITE.md` — public-facing marketing and landing pages.
- `MOBILE-APP.md` — touch-first mobile applications.
- `DESKTOP-APP.md` — resizable desktop applications.

## Usage

At project setup, select the primary interface type. Read `BASE.md` plus the relevant archetype, then generate the project's root `DESIGN.md`.

Do not load every archetype for every task. After the project `DESIGN.md` exists, use that file as the primary design source of truth.
