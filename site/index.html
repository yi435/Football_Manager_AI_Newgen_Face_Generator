How it works

Steps tagged Auto are handled by the app. Manual ones need you — about a minute in FM.

  1. Auto
    One-click installer. Checks your system, downloads the engine (ComfyUI) and the RealVisXL model, installs everything with a progress bar, and auto-starts the engine on launch. If an install piece ever breaks, Maintenance → Repair fixes it.
  2. Manual
    Export your player list. On FM24: apply the included filter, then Ctrl+P → To text file. On FM26 (which removed text export): install the free export plugin — see the box below.
  3. Auto
    Faces get generated. The app watches the export folder, builds a unique prompt per player (age, nationality, personality), and renders each face on your GPU.
  4. Manual
    Reload the skin in FM. Preferences → Interface, untick “Use caching”, then Clear Cache → Reload Skin — the new faces appear.

Want a different look? Use Edit Face Style… in the app to rewrite the prompt your faces are built from, and reset back to the defaults anytime.

Playing FM26? FM removed the text export — here's the fix

Install the free FM26 Player Export plugin (BepInEx) by vinteset. Then: set up the view, show the ID column, press F9, and the app reads its CSV/HTML exactly like an FM24 export. The in-app FM26 Setup… button links the download and can point your Watch Directory at the plugin’s output folder for you.

Quick start

A complete step-by-step — no prior knowledge assumed.

1/ Install the app (5 min)

Download FMNewgenGenerator.exe and run it. The setup wizard downloads the AI engine (~2 GB) and the RealVisXL model (~7 GB) with a progress bar, then installs everything under %LOCALAPPDATA%\FM Newgen Generator\. When it opens, wait for the status badge to turn green (“Connected”) — that means the engine is ready.

2/ One-time FM preferences (mandatory)

Open Preferences → Interface, untick “Use caching to decrease page loading times”, tick “Reload skin when confirming changes”, then Clear Cache → Reload Skin. Without this, FM won’t display the new faces.

3/ Export your newgens

FM24: download the filter above, place it in …\Football Manager 2024\filters\, open Player Search, apply it, Ctrl+A, Ctrl+P → To text file into your Watch Directory.

FM26: install the free export plugin, show the ID column, press F9. Point the Watch Directory at its output folder.

In both cases the export must include the ID column — the app maps faces by UID.

4/ Generate & confirm

Press Start Watcher in the app, then export in FM. Watch the log fill up as faces are produced. Finish with Reload Skin (step 2) and check a player’s profile.

FAQ ▸

Does it work with Football Manager 2026?

Yes — FM26 removed the classic text export, so the app reads output from the free FM26 Player Export plugin (BepInEx) instead. Show the ID column, press F9, and everything downstream is automatic.

The F26 plugin file is flagged by antivirus / SmartScreen

Normal: it’s an unsigned DLL off the internet. Right-click the DLL → Properties → Unblock, and if your antivirus removes it, add the BepInEx\plugins\FM26PlayerExport folder to exceptions. Full source of the plugin is public for verification.

The data export is empty or headers show “Col1, Col2…”

Press F8 in the plugin to re-scan the current screen, then F9 again. Make sure you’re on the Squad or Player Search screen, and that the ID column is visible.

It says “ComfyUI not connected” — what do I do?

The app auto-starts the engine and shows a green “Connected” badge once it’s ready. If it stays offline for over a minute, use Maintenance → Repair — it fixes a broken engine or a misplaced model download automatically.

Do I need a cloud / API key?

No. No subscription, no credits, no keys. Generation runs 100% locally on your NVIDIA GPU.

Does it touch my real-player facepack?

No. NewGen faces are written to a separate graphics folder with their own config, so existing facepacks stay untouched.
