# Final Implementation Plan - FM24 AI Newgen Face Generator

This plan outlines the architecture and implementation steps for building **FM-AI-Newgen-Generator**, a cross-platform Python GUI application designed to automate realistic newgen face generation for *Football Manager 2024*.

---

## 1. Goal Description
To replace the artificial 3D faces generated by Football Manager 24 with high-quality, photorealistic AI portraits. The tool will:
- Target **only newgens (regens)** and leave real-world players and existing facepacks untouched.
- Create realistic faces based on the player's **Nationality, Secondary Nationality (Ancestry), Age, and Personality**.
- Maintain **visual consistency as players age** (using their unique ID as the AI generator's random seed).
- Provide a simple, cross-platform **Desktop GUI application** to configure, run, and monitor the process.

---

## 2. Final Architectural Decisions (Aligned with User)

### A. Player Data Extraction (Watcher Method)
- Due to the risks of memory hacks (DLL injection) causing game crashes, we will use the highly stable **File Watcher** method.
- The user exports the list of newgens using `Ctrl+P` in the FM24 player search.
- The background Python script automatically detects the exported file in the `/exports` folder, processes it, and updates the faces.
- We will add a **notification system** to notify you on your computer when a save point occurs, reminding you to run the export if there are new players.

### B. Dynamic Aging with Seed Consistency
- Players' faces will update at key age milestones: **16, 20, 24, and 28**.
- To keep the player looking like the same person, we will set the generator's **random seed to their player Unique ID**.
- We will append age-specific text to the prompt:
  - **Age 16:** Clean-shaven, youthful features.
  - **Age 20:** Light stubble (where regionally appropriate), young adult features.
  - **Age 24:** Mature adult features, potential full beard/facial hair.
  - **Age 28:** Peak mature features, stylized hair/facial hair.

### C. Physical Features & Regional Presets
- We will implement a regional grouping database:
  - **Nordic / Western Europe:** Fair skin, high probability of blonde/brown hair, blue/green eyes.
  - **Mediterranean / Middle East / South Asia:** Olive/tan skin, dark hair/eyes, higher probability of full beards at older milestones.
  - **East / Southeast Asia:** East Asian facial features, dark straight hair, dark eyes, low facial hair probability.
  - **Sub-Saharan Africa:** Dark skin, dark curly/coiled hair styles.
  - **South American:** Mixed/tan/fair skin tones, dark wavy hair.

### D. Weighted Demographics for Multi-Ethnic Countries
- Countries like France, England, Germany, Belgium, USA, and Brazil will use a weighted probability mapping:
  - e.g., **France:** 70% European/Caucasian heritage, 20% African heritage, 10% North African/Arab heritage.
  - The script will roll a random number to select the ethnicity prompt for these players, ensuring the youth intake accurately mirrors real-world demographics.

### E. Graphics Folder Isolation (Separate Pack)
- The tool will write generated images to a separate folder (e.g., `graphics/AI Newgen Faces/`).
- It will write its own `config.xml` mapping file in that folder.
- Football Manager 2024 automatically merges multiple graphics directories, so your existing real-player facepacks will remain **100% safe and untouched**.

### F. Interface (Python Tkinter GUI)
We will build a clean, dark-themed GUI desktop window using standard Python `tkinter` (which works out of the box on both Fedora Linux and Windows with zero extra installations):
- **Directories Panel:** Text boxes with "Browse" buttons to set your FM `graphics/` directory and your watcher `exports/` directory.
- **Watcher Toggle:** A big button to "Start Watcher" or "Stop Watcher".
- **Progress Panel:** Shows a progress bar, a status label ("Watcher Idle", "Generating faces...", etc.), and the name/ID of the last processed player.
- **Settings Panel:** Toggle option for "Auto Reload Skin (Send Shift+R)" and "Concurrency Limit" (how many faces to download at once).
- **Log Console:** A small text window showing real-time logs.

## 4. Verification Plan

We will write a `verify_tool.py` script:
1. It creates a mock export file (`mock_export.rtf`) representing a new youth intake (with Japanese, French-Senegalese, and English players).
2. It runs the parser to convert it to a player list.
3. It generates custom prompt strings based on nationality, dual nationality, age, and personality.
4. It calls Pollinations.ai to download a sample image.
5. It compiles the `config.xml` entry and validates that the XML is formatted correctly.
